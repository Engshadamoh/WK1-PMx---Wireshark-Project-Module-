Wireshark SOC Labs - Internship Project

Welcome to my repository! This repository documents my progress and completion of the Wireshark SOC Labs project (Week 1 Extra Module from NetworkWalks).

As part of this project, I investigated 6 live security labs in my browser, using Wireshark skills to analyze network traffic, identify attackers, uncover hidden data, and track down suspicious activities. Each lab consisted of 10 practical tasks.

🛠️ Labs Overview

Lab 3: Identify the Attacker's IP (networkwalks.com/wireshark-lab3/)

Investigated network traffic to pinpoint the attacker's IP address and analyze port scanning behavior.

Lab 4: Follow TCP Stream 1 (networkwalks.com/wireshark-lab4/)

Rebuilt TCP conversations to read transmitted data and extract stream details.

Lab 5: Follow TCP Stream, Part 2 (networkwalks.com/wireshark-lab5/)

Practiced advanced TCP stream following on a new capture to find hidden data, code words, and file transfers.

Lab 6: HTTP Plain Text Credentials (networkwalks.com/wireshark-lab6/)

Located usernames and passwords transmitted in clear text over HTTP.

Lab 7: Catch the Brute Force Attacker (networkwalks.com/wireshark-lab7/)

Spotted repeated login attempts and identified password-guessing vectors.

Lab 8: Catch the Call Scammer (networkwalks.com/wireshark-lab8/)

Investigated packet captures containing VoIP calls to identify call scammers.
